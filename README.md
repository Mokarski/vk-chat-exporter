# VK Chat Exporter

Расширение для Chrome (Manifest V3), которое сохраняет историю переписки ВКонтакте в **JSON** или **Markdown** — без использования официального API, токенов и сторонних серверов. Всё работает локально в браузере.

> ⚠️ Расширение в первую очередь создано для **личного использования** (резервная копия своей переписки, экспорт учебных чатов, архивирование). Учитывайте право на неприкосновенность частной жизни собеседников и не публикуйте чужие переписки без согласия участников.

---

## Возможности

- 📥 Перехват сообщений из запросов `vk.com` (XHR + fetch) через инжект в MAIN world.
- 🧹 Автоматическая фильтрация UI-мусора (подсказки, onboarding-плашки, `keyboard:*`, `profile:*` и т.п.) — остаются только реальные сообщения и сервисные события (создание чата, приглашение участников и т.д.).
- 💾 Экспорт в **JSON** — полный сырой объект сообщения, удобен для дальнейшей обработки.
- 📝 Экспорт в **Markdown** — читаемая переписка с датами, авторами, вложениями (фото/документы/аудио/видео/ссылки/стикеры) и ссылками на файлы.
- 📎 Скачивание вложений (фото, документы, аудио, видео) отдельными файлами.
- 🔍 **Фильтр по чату**: можно указать `peer_id` вручную, несколько ID через запятую, либо определить ID текущего открытого чата кнопкой «Определить».
- 🗂 Сбор данных из всех фреймов страницы (VK грузит часть контента в iframe).
- 🐞 Панель отладки в попапе — показывает, какие запросы перехвачены в каждом фрейме.

## Установка

1. Скачайте или склонируйте этот репозиторий:
   ```bash
   git clone https://github.com/<ваш-логин>/vk-chat-exporter.git
Откройте chrome://extensions (или edge://extensions).

Включите Режим разработчика (переключатель в правом верхнем углу).

Нажмите «Загрузить распакованное расширение» и выберите папку с проектом.

Готово — в панели расширений появится иконка VK Chat Exporter.

## Ограничения
Прокрутите историю сами. Расширение видит только те сообщения, которые VK уже загрузил в ответ на скролл. Автоматической прокрутки и рекурсивной подгрузки нет.

Захват начинается после установки/обновления расширения. Сообщения, полученные до этого, в буфер не попадут — перезагрузите вкладку ВК перед началом работы.

Ссылки на вложения могут истекать. У фото/аудио/видео в VK подписанные URL с ограниченным сроком жизни. JSON/ Markdown сохраняются, но если скачать вложения позже — часть ссылок может уже не работать.

Зависит от внутренних эндпоинтов VK. Если VK изменит формат ответов или название методов, парсер в inject.js может перестать что-то находить. В этом случае поможет панель «Отладка» в попапе.

Не официальный клиент VK. Использование — на ваш страх и риск, соблюдайте правила VK и законодательство о персональных данных.
